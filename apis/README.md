# APIs

`apis/` contains authored API contract sources for SDKWork Agents.

Authoritative OpenAPI lives under `crates/sdkwork-intelligence-agents-service/specs/openapi/` and is indexed by `apis/agents/authority-index.json`.

Surfaces:

- `sdkwork-agents-open-api` — `/agent/v3/api`
- `sdkwork-agents-app-api` — `/app/v3/api`
- `sdkwork-agents-backend-api` — `/backend/v3/api`

Related: [`../sdkwork-specs/API_SPEC.md`](../sdkwork-specs/API_SPEC.md), [`docs/architecture/AGENTS_LAYERING.md`](../docs/architecture/AGENTS_LAYERING.md).
