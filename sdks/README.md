# SDKWork Agents SDK Families

SDK families for this application are owned by `sdkwork-agents` (not `sdkwork-kernel`).

| Family directory | Surface | npm package |
| --- | --- | --- |
| `sdkwork-agents-sdk` | open-api | `@sdkwork/agents-sdk` |
| `sdkwork-agents-app-sdk` | app-api | `@sdkwork/agents-app-sdk` |
| `sdkwork-agents-backend-sdk` | backend-api | `@sdkwork/agents-backend-sdk` |

Family registry: [`_shared/agents-sdk-families.mjs`](_shared/agents-sdk-families.mjs).

Internal runtime SDK remains in `sdkwork-kernel/sdks/sdkwork-agent-internal-sdk`.
